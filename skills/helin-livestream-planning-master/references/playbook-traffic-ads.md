# 流量获取与投流策略方法库（策划层）

> 只做策划层：投不投、投什么目标、分几个阶段、预算结构、止损与加投规则、与排品话术的配合。账户搭建、定向细节、千川掉量诊断不在本技能范围。平台工具参数见各平台文件。

## 1. 流量来源清单

策划时逐项写"来源 / 目标人群 / 入口内容 / 承诺点 / 进场后谁承接 / 预估量级依据"：

| 来源 | 常见入口 | 量级依据 |
|---|---|---|
| 预约 | 预约短视频、笔记预告、公众号预约按钮、私域海报 | 视频号按预约数预估（河林口径）；小红书预约到场约 30% |
| 私域 | 社群通知、朋友圈、企微 1v1、分享员/推客 | 私域规模 × 触达率 |
| 短视频/笔记引流 | 种草视频、切片、合集笔记 | 播放/阅读量，随机性大 |
| 公域推荐 | 开播极速流、上下滑、广场、发现页 | 不可承诺，只写影响因素 |
| 搜索 | 品牌词、品类词 | 品牌搜索量 |
| 付费 | 微信豆/ADQ、千川/随心推/DOU+、乘风/聚光 | 预算 ÷ 进人成本，未给预算不估 |
| 达人/合作 | 连麦、达人专场、买手 | 合作方历史数据 |

## 2. 投不投：判断顺序

1. **人货场是否验证过？** 没有承接能力时投流只会放大亏损，也可能拉泛人群、压制自然流。先用自然流或小额测试验证承接。
2. **保本 ROI 是多少？** 用 `scripts/live_calc.py roi` 算（考虑毛利率、签收率/退货率、平台扣点）。算不过来就不投或只投拉新/种草目标并接受亏损上限。
3. **钱从哪来？** 投流有账期，需要资金储备；预算过小测不出数据。
4. **自然流现状？** 自然流好的直播间谨慎叠加泛目标；自然流不足、需要建标签时可微付费。
5. **平台特点？** 视频号难以靠付费大规模放量；抖音付费为主但承接不住会反噬自然流；小红书投笔记拉预约常优于直投直播间。

结论只能是四种之一：不投 / 小额测试 / 按阶段投放 / 付费为主（需毛利 ≥ 约 50% 且有资金储备）。

## 3. 阶段策略

| 阶段 | 目标 | 常见做法 |
|---|---|---|
| 预热期（播前 1–14 天） | 预约、种草、蓄人群 | 投预约视频/预热笔记/直播预告；测哪类内容导流好 |
| 开播冷启动（前 30 分钟） | 有效进人、停留 | 开播即投，不拖到开播 1 小时后；配合福利品接住流量；小红书可用观看类放量目标抢有效观播 |
| 拉升期 | 成交 | 停留和商品点击好时通知投手放量；主推上播时间提前同步给投手 |
| 稳定期 | 成交 + 拉新 | 长计划铺底、短计划在节点爆发；守住新粉成交占比 |
| 收尾 | 收割或收缩 | 竞价弱的时段上利润款；大促后收缩预算、准备换品 |

## 4. 预算结构与规则模板

方案中写成规则，而不是写死金额：

- **保本线**：保本 ROI ≈ 1 ÷ [签收率 ×（毛利率 − 其他变动费率）]，与 `live_calc.py roi` 口径一致，用脚本算；目标 ROI 再留出净利空间。
- **测试**：新计划小额、多计划试错，单条计划消耗到一定额度（如数百元）仍无成交即关停。
- **放量**：连续 1–3 天（或连续几场）ROI 高于保本线才加预算，每次加约 20%–30%。
- **止损**：ROI 跌破保本线，或成本单日上涨超过约 30%，降预算或暂停。
- **占比上限**：知识付费/教培场投流不超过账号流量约 30%；大场可阶段性放低成本抢量，日常场守 ROI。
- **复盘**：前端 ROI 不含退货，等 7 天到半个月按确收重算后再决定下一场预算。

## 5. 投流与排品、话术的配合

- 投放素材卖点要与主播讲解一致；直播间承接的是素材带来的那群人。
- 起量慢的工具（如 ADQ）适合单爆品、长讲解；起量快的工具（如微信豆）适合过款直播间。
- 投流期间发福袋、上低客单品，计划容易跑泛；福利节点与投放节点要错开或提前规划。
- 用漏斗定位承接问题：有点击没停留 → 画面/主播开场；有停留没商品点击 → 讲品节奏/货架排序；有点击没成交 → 价格、评价、信任。承接不行时加预算越加越亏。
- 素材：好素材生命周期短（数天到两周），素材产出能力决定投流上限；投流素材优先从自然流跑得好的内容里挑。

## 6. 常见错误

1. 用投流掩盖内容和承接短板。
2. 只看支付 ROI 不看退款。
3. 投浅层目标（观看、商品点击、泛订单）烧掉大量预算。
4. 自然流掉了才慌忙投流。
5. 新号一上来就投深层成交且出价不足，跑不出去；或反过来长期只投浅层。
6. 迷信"牛投手"、签大额年框。
7. 预算全压在投流，不做种草和品牌。
8. 达播时品牌方擅自给达人投流，投坏账号标签。

## 7. 专家分歧的处理

- 付费是否压自然流、计划时长（短时 1–4 小时 vs 跟随直播时长）、冷启动用控成本还是放量、新号投浅层还是深层——各方说法相反。方案中写出所选做法和理由，并设计一个可验证的小实验（例：前两场用短计划，对比自然流占比变化）。
- 不承诺任何 ROI、消耗量或进人成本。
