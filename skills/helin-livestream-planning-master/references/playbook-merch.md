# 排品与营销玩法方法库

> 跨平台通用方法。平台特有参数见对应平台文件，河林判断见 `helin-method.md` 第 3–4 节。

## 1. 排品四步

1. **定主推**：用爆品条件筛（应季刚需 + 性价比、库存货值足、好展示、有数据验证、有独特卖点、中高客单有利润）。主推 1 个，最多 2 个。
2. **配角色**：围绕主推安排福利/引流、承接/次推、利润、形象、清仓/测试款。每个品写一句"它怎么服务主推"。
3. **排动线**：决定出场顺序、返场频次、过渡品和福利回拉点。
4. **算坑产**：`scripts/live_calc.py pit` 计算各品预估产出和缺口，缺口用加品、拉单品、延播、加预算/预约补。

## 2. 货盘角色表

| 角色 | 任务 | 定价与机制要点 | 常见错误 |
|---|---|---|---|
| 福利/引流款 | 开场密集成交、中段拉在线、给新人一个"值"的理由 | 看着贵、实际划算；分批放；电商自然流慎用 1 元/9.9 元（低价标签），可组合成"高客单引流"；引流品价格可设为下一档正价品的约 30%–40% | 恋战；引流品吃掉预算全是凑单；与主推人群不一致导致切换掉人 |
| 承接/次推款 | 补足品类、风格、场景，在主推间过渡 | 同价位或略低，接住福利款带来的人 | 数量过多分散注意力 |
| 主推/爆品 | 整场产出主力，反复返场 | 组合装、套组、赠品搭配拉客单 | 讲太久不出单；库存不够撑返场 |
| 利润款 | 贡献利润 | 毛利高、可在主推之后接同价位 | 卖不动还硬讲 |
| 形象款 | 制造价格断层，锚定主推 | 高客单、深讲不催单 | 用形象款冲业绩 |
| 清仓/破价/测试款 | 清库存、测新品 | 测品用"上架不讲看点击"或 AAAB 穿插 | 破价伤主推和老客 |

河林提醒：判断角色看用户感知的综合性价比，不只看价格；每个品的属性、质量要配得上它的定位。

## 3. 排品模型与适用条件

| 模型 | 做法 | 适用 | 不适用 |
|---|---|---|---|
| 单爆品循环 | 一个主推反复憋—卡—踢—促或讲—卖循环，穿插福利 | 抖音、视频号付费直播间；有明确爆品 | 缺爆品、需要多 SKU 满足的服饰上新 |
| 福利—承接—主推（火箭式） | 福利拉人 → 承接过渡 → 主推收割 → 福利回拉 | 视频号专场、达人混场 | 小红书慢节奏场次（改信任链） |
| 价格阶梯 | 从凑单小件逐级上到主品与高客单，讲当前款时预告"一个更好的" | 家纺、日用、食品等多 SKU 品类 | 高客单单品 |
| 爆款带新款 | AAAB → AB → ABB，用老爆款流量测新款 | 有成熟爆品的店播 | 新号 |
| 混场改单品 | 某条短视频或某个品数据明显跑出，临场改为单爆品专场 | 有备货、投放能同步换素材 | 库存浅 |
| 节目化/形象款开场 | 情绪或内容开场 → 形象款建调性 → 走量款集中上 | 小红书、高客单、明星/主理人 | 低客单走量 |
| 产品阶梯（知识付费） | 引流品 → 低价课 → 正价 → 高客单 | 课程、会员、咨询 | 没有后端交付 |

服饰补充：穿搭组合、价位梯度、提前种草；相似款分到不同轮次，先过库存充足款；克制上品数以控退货。

## 4. 营销玩法工具箱

| 工具 | 目的 | 触发时点 | 成本与风险 |
|---|---|---|---|
| 预约 + 开场福利 | 接住开播极速流/预约流 | 开播 0–10 分钟 | 福利品要真实有量 |
| 福袋 | 拉停留、拉在线 | 掉人时、半点/整点节点 | 诱导评论违规；投流时易让人群变泛 |
| 截屏/晒单抽奖、免单 | 促单、晒单反哺口碑 | 主推每轮成交后 | 规则要提前公示 |
| 满赠/阶梯赠 | 拉客单、连带 | 主推开价时 | 用 `mech` 算让利 |
| 组合装/多件装 | 拉客单（单个卖不动时主推两件装） | 主推开价 | 讲清场景（全家/囤货） |
| 价格锚定 | 塑造获利感 | 开价前 | 对比价必须真实可查，禁止虚构划线价 |
| 真实库存分批放单 | 制造集中成交波峰 | 每轮开价 | 仅限真实库存；禁止虚构"最后几单" |
| 灯牌/粉丝团/会员专享 | 强化老粉、转粉 | 开场与转粉节点 | 不以灯牌数设置不合理门槛 |
| 预售/定金 | 高客单降低冲动退货 | 大场或高客单 | 讲清履约时间 |
| 限时返场/整点加库存 | 反复拉动爆品 | 每小时节点 | 时间与库存必须真实 |
| 确认收货后兑现福利 | 降退货 | 全场 | 写清规则 |
| 无理由退款/试用名额 | 降决策门槛（高客单、课程） | 开价后 | 名额真实，兑现成本算入 |

## 5. 成交循环（三种）

- **憋—卡—踢—促**（抖音、视频号电商）：以上链接为锚点，5–15 分钟一轮；只在真实库存/名额下使用卡和踢；视频号近期对"过度营销逼单"治理趋严，偏向"微憋单"——讲福利理由不报价 → 核心卖点 → 互动放单 → 讲稀缺与保障 → 控单递增。
- **信任转化链**（小红书、高客单、讲解型）：痛点/场景 → 讲解与证据 → 机制与利益点 → 预期管理与售后 → 下单指令。
- **讲—卖循环**（知识付费）：按价位段决定讲与卖的比例，见 `model-knowledge-leads.md` 第 3 节。

## 6. 机制算账

- 每个机制写清：给什么、给多少份、单份成本、触发条件、预计参与人数，用 `scripts/live_calc.py mech` 汇总让利总额，并与本场毛利对比。
- 让利总额超过预估毛利的一定比例时，在方案中标红并给替代机制（换赠品、改为确认收货后兑现、改为抽奖）。
- 不知道成本时写〔待确认〕，不编数字。
