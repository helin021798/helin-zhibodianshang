# 塑品与成交话术方法库

> 话术写成"固定结构 + 替换变量"，不写成背诵稿。所有稀缺、比价、功效、承诺类句式过 `compliance.md`。行业经验为转述提炼。

## 1. 主骨架：五步成交

每一步回答用户心里的一个"为什么"：

| 步骤 | 回答 | 参考时长 | 关键要素 |
|---|---|---|---|
| 留人 | 为什么停下来 | 30 秒–1 分钟 | 钩子、人群点名、场景 |
| 价值 | 为什么要买它 | 2–3 分钟（最长） | 痛点→卖点→证据→拥有后的体验 |
| 比价 | 为什么在这里买 | 30 秒–1 分钟 | 真实价格锚点、机制、赠品 |
| 保障 | 为什么放心买 | 约 30 秒 | 7 天无理由、运费险、试用装、售后承诺 |
| 稀缺 | 为什么现在买 | 15–30 秒 | 真实名额/时限，或"提前准备"类理由 |

跳步和乱序是转化差的首要原因（如一上来就报价，跳过了价值）。逼完一轮回到价值，再走比价—保障—稀缺。

河林版逼单链路可与之对照：痛点 → 价值塑造 → 价格锚定 → 亮价 → 紧迫感 → 库存施压（仅真实库存）→ 售后兜底。

## 2. 开场与留人

- 来人后第一件事是控场，不是背话术；不要一开场就满音量亢奋，30 分钟后主播和观众都会累。
- 不说"听我说一分钟"，直接种草。
- 钩子三类：福利钩子（新进来的打 1，先体验不是先卖）、知识钩子（怎么挑到真正好的［品类］，看这［N］点）、话题钩子（与人设相关的私人话题）。
- 场景人群锚点：如果你［具体人群］总是［具体糟心场景］，先别划走。
- 归因转移：你［反复出问题］，可能不是你的问题，是［产品］选错了。
- 懂你式：［人群标签］+［两个常见的坑］+ 点破"不是舍不得花钱，是怕花得不值"。
- 同病相怜：有没有跟我以前一样［痛点］的？+ 主播真实经历。
- 新人身份：第一次来的打 1，新人有见面礼（礼物必须真实）。
- 河林：开播 5–10 分钟预约流集中进入，要快速讲清主题、机制和最大利益点，峰值到了立刻开福利品。

## 3. 塑品

### 卖点 → 买点

- 种草公式：在我［痛点场景］的时候，用它会让我［情绪收益］。
- 功能翻译：功能 → 在［具体场景］下 → 用户能［具体好处］→ 避免［具体痛苦］。人群、场景、痛点、产品四要素都要具体，任何一个抽象，购买理由就垮。
- 痛点从客服记录、评价区、用户访谈收集，不凭想象。
- 先讲感受和好处，再讲原理；调动听觉、触觉、味觉等感官，用比喻带情绪。
- 塑价值不等于讲卖点：价格是用户付出的，价值是用户得到的；多讲拥有之后的体验，必要时做身份投射。
- 河林：背书、专利、企业历程放在卖点的"789"位；对新客不讲术语；主播要成为品类"半个专家"。

### 结构化讲法

- 按品类拆三项价值，用递进衔接词串起（看好 → 而且 → 还不够 → 重点是），层层递进，不平铺。
- 一个点讲透：同一卖点讲 3–4 次，每次上一层——报事实 → 演示场景 → 预判疑虑并击破 → 情感升华。
- 重点放慢、重要的事讲三遍；脑子里装的是"为什么买它的一二三"，不是背下来的词。

### 证据

- 卖点证据矩阵：3 个不重叠卖点（功能型、场景/情绪型、信任/差异型）× 每个卖点 3 种画面证据（特写、场景、对比、上身/上手、证言、前后、借物）。
- 卖点内容化三重境界：念出卖点 → 演出卖点（现场实验）→ 用身体能感受的符号具象化（如冷凝水珠代表冰爽）。
- 现场实验示例：捂 3 秒测温、拧了不皱、蒸汽透气、涂层实验、真人试穿特殊身材。
- 差品对照：先体验同类差品，痛点讲得真实、卖点讲得愉悦，形成反差（不点名诋毁同行）。
- 原理型、亲身体验型、检测报告、对比视频循环播放。背书只做过渡，不拉长。

### 价格锚定（必须真实）

- 向上对比真实可查的参照（同价位大牌单品、专柜价），不虚构划线价，不贬低廉价同类。
- 成本拆解、等价换算（营养/用量折算）、单次价值、按场景拆价。
- 价格梯度报价（直播间逐级让价）只在价格确实存在时使用。
- 低价理由要真实（新品首发、平台补贴、清货），"我不挣钱、赔本卖"没人信还伤信任。

## 4. 互动与控场

- 沟通式塑品：把卖点改成回答用户问题；给刚进来的人复述重点。
- 停顿制造沟通感：抛反问、停一下、表情不掉。
- 控场挂载：留人、塑品、保障、稀缺的关键句都配控场，每 5–20 秒一次——身体前倾、眼神坚定、语气重且慢、"称呼 + 指令"。
- 没人互动时自问自答（复述真实问过的问题），不说"你们怎么不说话"。
- 互动指令可用"想要的扣［字］"做意向确认，但不得以领福袋等利益诱导评论。
- 节奏切换：来人放钩子；人稳住了塑品、逼单；卖得好继续逼单；卖得不好关单重新拉新一轮。留存掉了加讲痛点，互动冷了抛福利钩子。

## 5. 逼单与促单（合规版）

- 软逼单/给决定权：我不是催你 + 这一轮结束要等［真实周期］+ 先拍下占名额，主动权在你（配合无理由退）+ 老粉真实反馈。讲完立刻回到塑品。
- 提前准备型：不是需要了才买，是提前备好 + 描绘突发需要的时刻 + 那时没有它的难受。
- 走心型（文艺、高客单）：体验和陪伴价值；"花这钱不影响生活质量，就该花"。
- 确定性损失：明确告诉真实的机制截止点（如本场赠品只在本场），用户避免损失的动力强于获得。
- 两种人格：快语速、强调价格适合低客单冲动品；慢语速、闺蜜分享感适合中高客单。
- 禁用：生硬的"大家快去下单"；"最后两单""最后 3 分钟"类无法证实的说法；虚构库存、假踢单。

## 6. 异议处理

| 异议 | 结构 |
|---|---|
| 嫌贵 | 先把价值讲足再报价；换参照系（和同价位比而不是和低价货比）；替用户说出"怕花得不值"再回应 |
| 怕假 | 不说"绝对是真的"；给细节特写、产地/资质、拍回去拆开看、运费险兜底 |
| 怕不适合 | 试用小包、不合适可退、现场真人试穿/试用 |
| 怕跟家里的一样 | 先承认担心，再给差异证据 |
| 怕售后 | 7 天无理由 + 运费险 + 售后流程讲清楚 |
| 怕效果过度承诺 | 先降预期（"它不是一夜见效"），讲正确使用方式和合理周期 |
| 问价格 | 引导看购物车实时价格和赠品 |

主动预判疑虑并自答，效果好于等用户问。

## 7. 品类要点

| 品类 | 价值三要素 | 演示 |
|---|---|---|
| 服饰 | 面料、版型、细节 | 揉搓听声、垂坠、拧/蒸/拉、多身材试穿、穿搭 |
| 美妆护肤 | 效果、持久、肤感、适用肤质 | 半脸对比、主播本人展示（不宣称医疗功效） |
| 食品 | 味道、口感、配料表 | 现场试吃、营养等价换算、新鲜度证明 |
| 家居日用 | 材质、工艺、使用场景 | 成本拆解、涂层/耐用实验 |
| 课程服务 | 结果路径、师资、案例、交付 | 现场诊断、学员案例（授权）、试听/体验 |

## 8. 知识付费话术

- 知识钩子：用［N］分钟教会你［小结果］，再给资质证明（真实）。
- 专业服务：先问人群痛点 → 推演后果 → 讲方法；专业资历 + 筛选客户的姿态。
- 短口播三句式：痛点"你是不是也……"、方法"其实只要……"、鼓励"我也是普通人……"。
- 课程卖点讲"我本人亲自带"、方法数量、交付形式；不承诺收入、提分、通过率等结果。

## 9. 主播训练

- 播感四档情绪：讲痛点有痛感，讲卖点愉悦，讲福利有力度，讲保障和人设走心；拉大痛点与卖点之间的情绪落差。
- 每天录同一句话的多种语气，回看选最好的；节奏练"慢—停—加重—继续"。
- 轻快打底、关键处重慢；对任意物品即兴讲 3 分钟；多回看录播。
- 回放按五步逐段打标签，找出卡在哪一步。
