# 节奏、分工、场控与复盘方法库

## 1. 节奏表设计

- 按直播时长切阶段：开场预告/福利接流 → 主推第一轮 → 承接与福利回拉 → 主推返场 → 利润/形象款 → 收尾与下场预约。
- 每个阶段写：目标、产品/内容、主播动作、团队配合、互动设计、切换条件、风险预案。
- 讲品节奏参考（河林）：主推首轮 15–20 分钟、到 20–25 分钟开单，之后每轮约 5 分钟；多品场 5–10 分钟不出单就切；避免一个品讲 40 分钟、后 20 分钟没单。
- 快节奏平台一轮成交循环 5–15 分钟；小红书和高客单放慢；知识付费按价位段定讲卖比例。
- 爆品承载：每小时约 20 分钟爆品 + 40 分钟承接，爆品每小时返场。
- 设计三类恢复点：福利回拉（掉人）、答疑段（犹豫多）、主推返场（流量回升）。

## 2. 场控决策表

| 信号（可观察） | 判断 | 动作 |
|---|---|---|
| 在线持续下降、评论变少 | 货不对或讲得不好 | 换品、上福利、发福袋、要互动、换话术 |
| 推荐流/进人明显上升 | 有新流量 | 先留人（钩子、复述重点），再转最有潜力的品 |
| 曝光点击率和点击成交率都升 | 品对、讲对 | 继续讲，加密成交 |
| 两者持平 | 意向在积累 | 用真实库存的放单、逼单转化未支付订单 |
| 两者都降 | 品已到顶 | 马上过款 |
| 未支付订单多 | 犹豫用户多 | 讲保障、答疑、真实名额提醒 |
| 新人进来就走（1–3 秒） | 场景/画面问题 | 调画面、样品居 C 位、开场话术 |
| 3–20 秒走 | 品或人群不准 | 调货或调投放人群 |
| 20 秒以上才走 | 话术问题 | 调塑品话术 |
| 上链接就掉人 | 内容人群与电商人群不一致 | 一个直播间聚焦一种人群 |

下播判断：近半小时在线持续下降、推荐流见底，近 5–15 分钟无新评论、无新成交、待支付清零。

## 3. 团队分工

| 角色 | 播前 | 播中 | 播后 |
|---|---|---|---|
| 操盘/运营 | 立项、货盘、机制、预约资源、排期、磨话术、彩排 | 信息枢纽与决策：盯数据、提醒主播、换品返场、对接投手与品牌方 | 复盘、对盈亏负责 |
| 主播 | 熟悉产品、试用、练话术 | 话术 + 节奏，懂数据 | 回看录播、标注卡点 |
| 助播 | 准备演示道具 | 试穿试用、补充讲解、配合捧哏（"三分逗、七分捧"） | 收集高频问题 |
| 场控/中控 | 链接、价格、库存、贴片 | 上下架、改价、报库存尺码、发福袋 | 导出数据 |
| 投手 | 计划预建、素材 | 按节点调计划、反馈节奏建议 | 按确收重算 ROI |
| 客服 | 话术库、售后预案 | 答疑、合规承接 | 售后、私域沉淀 |
| 编导/内容 | 预约视频、种草笔记 | 切片 | 复用素材 |

最小配置：1 运营 + 1 主播；视频号场控中控可一人兼任；没有姓名时用角色名。

播前检查：画面、网速、功能、音量与背景音乐、弹幕、商品上架与价格、库存、客服自动回复、应急设备；彩排不用主账号消耗预约。

## 4. 风险与应急预案清单

机制/价格设置错误、库存不足或超卖、设备与网络故障、断播/违规提示、负面评论与舆情、主播状态、售后集中投诉、退货率异常。每项写：触发信号、第一动作、负责人。

## 5. 指标体系

| 层级 | 指标 |
|---|---|
| 流量 | 预约数与预约进场率、场观、曝光进入率、流量构成（推荐/预约/私域/付费/短视频）、付费占比、平均在线、新人在线 |
| 停留互动 | 人均观看时长、有效进房（>30 秒）、互动率、涨粉率、加团率 |
| 转化 | 商品曝光点击率、点击成交率、成交密度（每 10 分钟能否形成一波）、GPM、客单、主推单量 |
| 人群 | 新老客成交占比、画像与目标人群一致性 |
| 结果 | 去退款 GMV、结算/签收率、退货率、毛利、投流 ROI（按确收） |
| 知识付费 | 留资率、加微率、到课/完课率、私域转化率、48 小时转化 |

基准值都有条件，见平台文件，不跨平台、跨客单价套用。

## 6. 复盘

- 复盘不是念数据，也不是互相指责：找异常值 → 判断影响 → 回溯到动作和话术 → 好的固化、差的给可执行改动。
- 分两条线：**没人气**看曝光、曝光进入率、人均时长、流量曲线；**没成交**看 GPM、漏斗、客单、成交密度。
- 校准表：

| 现象 | 证据 | 原因假设 | 下场改动 | 验证指标 |
|---|---|---|---|---|

- 只有数据支持时写原因结论，否则标"待验证假设"；下一场只保留被数据或一线反馈支持的改动。
- 节奏：日复盘（10–15 分钟，三件必须改的事）、周复盘（到人到期的动作清单）、月复盘（目标与资源）。
- 确收复盘：等 7 天到半个月重算实际毛利与投流盈亏。
- 有回放文稿时，可调用直播拆解技能先拆，再回到本技能做下一场。

## 7. 症状—原因速查（诊断救场模式用）

| 症状 | 先查 | 第一动作 |
|---|---|---|
| 开播没人 | 预约量、开播时段是否稳定、私域通知、近期数据与违规 | 补预约与私域通知；固定时段；必要时小额付费 |
| 有人但留不住 | 场景、开场 30 秒话术、人群精准度 | 改画面和开场钩子；校准投放人群 |
| 留得住但不点商品 | 讲品节奏、货架排序、福利吸引力 | 缩短塑品到开价的距离；调整货架 |
| 点了不买 | 价格锚点、评价、信任、保障 | 补证据与保障；调整机制 |
| 只有老粉买 | 货盘只服务老粉、拉新渠道缺失 | 拉新品 + 新流量来源（短视频/投流），见 `helin-method.md` 第 11 节诊断库第 5 条 |
| 投了不赚钱 | 保本 ROI、退货率、承接漏斗 | 先算账；承接不行先停投 |
| 场观稳定但 GMV 低 | 缺爆品、客单尴尬 | 重新押爆品，见 `helin-method.md` 第 11 节诊断库第 6 条 |
