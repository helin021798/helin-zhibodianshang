# 知识付费 / 线索获客直播：业态模型

> 适用：卖课、训练营、会员、咨询、高客单服务（教育、留学、健康、家居、B2B 等）的留资、加微和成交直播。河林判断见 `helin-method.md` 第 10 节，本文件补充行业经验（转述提炼，括号内为原资料时间）。教培与虚拟商品监管变化快，务必同时读 `compliance.md`。

## 1. 与电商带货的根本差异

| 维度 | 电商带货 | 知识付费 / 线索获客 |
|---|---|---|
| 成交位置 | 直播间当场成交 | 直播间完成信任与筛选，正价/高客单多在私域成交 |
| 直播目标 | GMV、GPM、成交密度 | 留资率、加微率、引流品成交、到课/完课率、私域转化 |
| 关键资产 | 货盘、库存、机制 | IP 信任、案例、交付能力、私域销售团队 |
| 组织 | 主播、运营、场控、投手 | 再加班主任/顾问/1v1 销售 |
| 主要风险 | 虚假宣传、虚构稀缺、退货 | 效果承诺、资质（ICP、类目准入）、导流违规、退款与客诉 |

河林："任何线索获客的项目，最有效的方式就是公域直播"；成交放在私域，"不要期待在公域把所有的事情都做到"。直播目标要写成留资/加微/引流品/定金这类直播能直接影响的指标。

## 2. 成交路径与产品阶梯

通用阶梯：**引流品（0–19.9 元）→ 低价课/小正价（199–499 元）→ 正价课（1999–3999 元）→ 高客单（陪跑、私教、线下课、咨询，数千到数十万）**。各级任务：引流品负责筛人（不图赚钱），主力品可规模化，高价品不图规模；三层要递进，前后端产品必须一致。

常见链路样本（量级参考，非承诺）：

| 链路 | 关键数据 | 时间 |
|---|---|---|
| 直播卖 9.9 元评测 + 音频课 → 班主任企微 → 私域讲师直播卖千元课 → 进阶营 | 评测转化约 6%；私域直播稳定 15% 以上 | 约 2021 |
| 直播间 0 元引流 → 21 天回直播间打卡 → 测评解读 → 2980 元课 | 转化从约 3% 做到 10% 以上 | 约 2022 |
| 笔记挂 298 元 1v1 咨询（兼做筛选）→ 微信咨询 → 数万元服务 | 咨询付费比例高 | 约 2023 |
| 9.9/19.9 元体验课 → 问卷初筛时间与价格异议 → 短线/长线团队分开跟进 | 转化 5% → 12%–15% | 2026-03 |
| 直播卖 980 元线下课门票（中间不做低价承接）→ 线下转高阶 | 小场次无投流也能成交 | 河林案例 |
| 直播卖年度会员（只涨不打折）→ 社群 → 线下课 → 俱乐部 → ToB | 会员进群率高 | 2026 |

反面教训：中间层产品无法再转高客单（例：348 元标准课卖完就断了），引入私域必须有后续高客单交付；只做单次生意、客诉太多的机构会被市场淘汰。

## 3. 价位段决定讲卖节奏

| 价位 | 参考转化/留资率 | 讲卖节奏 |
|---|---|---|
| 0 元留资 | 留资率 0.5%–5% | 讲干货、给资料钩子 |
| 十元档 | 转化 2%–5% | 高频循环，"卖卖卖" |
| 百元档 | 转化 1%–2% | "讲卖讲卖"：讲 20–30 分钟、卖约 15 分钟，循环 3–4 次 |
| 千元档 | 转化 0.3%–0.5% | "大讲小卖"：讲约 90 分钟、卖约 30 分钟，一场只循环一次 |
| 万元档 | — | 1v1 咨询或大场发售 |

（2025，一家内容创业机构的经验口径。）

## 4. 流量获取

- 两种流量模型（视频号教培）：**电商型**——场观不大但人均产值高，适合内容、信任、价值塑造都强的老师，流量少卖得多时不要过早拉大流量；**内容型**——场观与销售约 1:1（平台均值约 1:0.8），适合客单不到千元的老师。
- 冷启动标志：2 小时场观稳定破 2000；粉丝量与直播权重无关。起号优先私域起号，其次微付费。
- 场观不必大：几百场观、全是精准高净值用户，也能支撑一个高客单商业模式。
- 爆款短视频就是开播信号：一出爆款立刻开大场预约；人设视频火了马上开播，直播话题承接爆款。
- 线索短视频结构：开头圈人群 → 问题 → 人设 → 解决思路 → 资料钩子。
- 微信生态"三级火箭"：公众号建信任 → 直播提效率 → 跑通后（ROI>1）再用投流放大；微信内引流 2–3 步，跨平台 8–10 步。
- 直播引流精准度通常高于短视频；小红书知识博主日常直播 1 小时可引流十几个精准用户（2024）。

## 5. 直播脚本与话术

### 循环脚本（适合引流品/低价课，3 小时可循环 9–10 遍）

| 时段 | 内容 |
|---|---|
| 0–3 分钟 | 钩子开场：点名目标人群和他们的处境 |
| 3–8 分钟 | 干货，只讲"第一步" |
| 8–12 分钟 | 普通人案例（真实学员，需授权） |
| 12–18 分钟 | 痛点激活 + 产品发售（权益堆叠、价值锚点） |
| 18–20 分钟 | 逼单：低价的意义（"买一个开始的机会"）、真实名额、无理由退款保障 |

### 教培直播禁忌

- 不要把直播间当授课场，知识只是铺垫；过于专业会干扰价值判断。
- 亲和力是前提，内容力决定客单价。公域为主时，每天播同一套内容并打磨到极致。
- 让学术型讲者直接讲讲座式直播，常常只有自己的学生在互动。

### 信任与成交

- 人际信任三要素：权威、相似性、口碑；沟通要进入"谈感受、共情"的层次；"用户认知不到的时候，不进行销售"。
- 高客单信任递进：互惠 → 承诺与兑现 → 信任状 → 好评与案例 → 痛点 → 真实稀缺；平均成交周期约 2 周。
- 成交脚本顺序：场景 → 向往或恐惧 → 产品 → 价值塑造 → 报价与对比 → 当下下单理由（先塑价值后报价）。
- 1v1 销售：报价越晚越好；多讲案例、少讲产品；顾问式五步——问现状 → 找真因 → 定问题 → 给对策 → 配产品；分期降低决策门槛。
- 体验课结构示例：独家性 → 差异 → 师资 → 原价锚 → 直播间体验价 → 无风险退款 → 真实名额。
- 专业服务话术：先问人群痛点 → 推演后果 → 讲方法；姿态是专业资历 + 筛选客户。

## 6. 玩法

- 分批抽奖（越贵的奖越往后放）、全程观看奖励、点赞集体目标；不得以转发朋友圈作为领奖条件（诱导分享）。
- 21 天回直播间签到打卡；多个助教直播间错峰做备份。
- 直播中提到一份资料，让用户找各自的运营/顾问领取，增加触点。
- 连麦诊断学员案例；组合权益（主课 + 小班 + 1v1 + 工具 + 线下门票），配合短期无理由退款降低决策门槛。
- 大场发售五步：积累预约（短视频贡献大部分预约）→ 刚需 + 意义感召 → 真实稀缺 → 投流放大 → IP 本人亲自卖第一波。
- 连麦不可控、门槛高时，用标准化循环脚本替代。

## 7. 私域承接链路

- 公私域四步：公域用内容和分享建信任 → 用留资组件或低价课导入私域 → 私域深度运营 → 回直播间（或私域直播、1v1）成交正价。
- 课包书：书包课改为"课包书"（必须加微信才能听课），加微率大幅提升（2026）。
- 黄金 48 小时：进私域 48 小时内安排公开课或咨询；"随流量转化"可把周期压缩到 1–2 天。
- 防止过度转化：低价课没听完不推正价课；未转化用户先轻交付，1–2 周后再激活。
- 锁定期与召回：每个用户设约 12 天跟进期，到期未转化用新钩子召回、换顾问跟进。
- 欢迎语 A/B 测试、按标签一对一推送内容，能明显提升回复率和留存。
- 社群活跃周期越来越短（约 3–5 天），改用个人号 + 短期"闪群"（7 或 14 天）。
- 私域直播结构：讲师主讲干货、副播循环介绍产品优惠；2 小时插 4–5 轮促单，第一轮在开播 20–30 分钟；最后半小时贡献大半成交；按 3–5 分钟切片对照成交单数找关键转化点。
- 训练营内二次转化：第二周开始转下一门课，先开放答疑、再布置小任务、第三天直播发售。
- 直播回放也能成交；用 AI 复盘直播录音检查转化逻辑。

## 8. 投流

- 视频号教培（未标日期口径）：投流不超过账号流量体量的 30%；单场投入越大 ROI 越低（头部约 5 万/场 ROI 约 1.5，腰部约 1 万 ROI 约 2，2000 元以内 ROI 约 3）；当场 ROI 微信豆约 2、ADQ 约 1.2；有老用户可用一方数据包找相似人群。
- 视频号 ADQ 线索：加企微约 50–100 元/个，表单约 60–120 元/个（2025-10），适合一单赚几百到几千元的生意。
- 三平台线索工具：抖音用本地推（目标选"获取线索"）；小红书用聚光投私信开口和留资（有最低消耗要求）；视频号挂体验课商品投成交。投流素材只从自然流跑得好的内容里挑。
- 先有 IP 信任再投：没有 IP 本人出镜的素材，客资成本可能翻倍。
- 冷启动预算：每个平台准备一笔测试预算，积累 10–20 个成交客户数据后系统才能学会推精准人群。
- 获客团队总成本应控制在营收约 30% 以内，超过一半即亏损。
- 微信端获客成本通常低于抖音和小红书（2025-12 观点）。
- 视频号现阶段投人设视频常优于直投直播间；ROI 打平即可放量的前提是有可靠后端。

## 9. 指标与基准

| 指标 | 参考 | 条件 |
|---|---|---|
| 公域互动人数占比 | 5% 算优秀 | 视频号教培 |
| 内容型直播商品点击率 | 要求约 5% | 视频号，知识直播 |
| 下单后加好友率 | 直播间约 70%、短视频约 60% | 约 2021 |
| 加微率 | 课包书可达 90% 以上 | 2026 |
| 私域转化率 | 千元以上课 10%–15% 算高；成人教培免费流约 1%、付费流约 5% | 2025 |
| 小红书留学聚光 | 私信成本 80–100 元，加微成本 180–200 元，转化 1%–3% | 约 2023 |
| 教培退款率 | 低于 5% | 视频号教培 |
| 人均停留 | 知识直播可拉到 8–10 分钟以上 | 系统性内容 |
| 业绩公式 | 线索 × 转化率 × 客单价，看 48 小时转化 | 私域销转 |

## 10. 平台差异速查

| 平台 | 主路径 | 注意 |
|---|---|---|
| 视频号 | 天然主场：直播 → 微信小店客服/公众号/企微 → 1v1 或私域直播；可挂 5–19.9 元体验课 | 个人开通留资组件门槛高；卖课需 ICP 备案；导流口径持续收紧 |
| 抖音 | 本地推/小风车等官方组件留资；书课包 | 教培类目 2026 年起定向邀约与类目调整；9.9 元以下课很难加微；虚拟课需搭配实物；效果承诺词会封店 |
| 小红书 | 笔记 + 直播获取线索，官方留资组件与群聊承接 | 2025-03-12 起禁止官方组件外的站外交易引导；2026-04 起成人/儿童教育类目个人店不可售 |
