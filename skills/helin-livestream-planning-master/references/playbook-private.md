# 私域联动方法库

> 河林的公私域联动判断见 `helin-method.md` 第 7 节。导流方式必须是平台当前允许的合规路径，见各平台文件与 `compliance.md`。

## 1. 私域在直播链路中的三个作用

1. **开场极速流**：预约和社群通知把精准老粉在开播时集中带进来，帮助冷启动、修正人群模型。
2. **关键节点补位**：主推成交时集中拉核心粉；在线下滑时补在线。
3. **成交后承接**：复购、升单、高客单 1v1、老带新。

私域要双向：只把私域往直播间导、不把直播间新客沉淀回私域，私域会"只出不进"。

## 2. 播前：蓄水与通知

- 节奏样例：倒计时海报（每天一个卖点 + 悬念问题）→ 社群内容种草（图文、问答、试用反馈）→ 开播前 72 小时预告品、价、赠品 → 开播当天两三次触达。
- 社群通知讲清"这场直播对我有什么好处"；群活跃低时改为个人号 1v1 触达。
- 私域种草做深度：公域视频做广度，私域图文把卖点讲细、讲透（不越过平台规则和广告法）。
- 投票/试用招募：既是调研也是种草，帮助确定主推。
- 高意向用户引进"直播专属群"，开播时 @所有人、发真实福利提醒。
- 朋友圈承接比例参考：人设、认知、专业、转化内容按约 3:3:2:2；每 10 条最多约 2 条卖货。

## 3. 播中：导流与承接钩子

| 业态 | 做法 |
|---|---|
| 电商 | 每过一个主推把直播间转发到群一次；爆品时拉核心粉；直播中弹下一场预约；成交后通过订单页客服、包裹卡等合规入口沉淀 |
| 知识付费/线索 | 资料钩子（"找你的顾问领取"）、低价课/体验课挂车、官方留资组件；"课包书"让听课必须加微 |

- 不在直播间口播微信号、不放二维码（电商直播常被罚）、不在评论区和客服里发联系方式。
- 分享员/推客可把私域转发转成增量（以平台规则为准）。

## 4. 播后：分层承接

- 订单用户：核单与售后服务为由合规添加 → 首次互动给价值（使用指导、售后通道）→ 按价值分层（已购高潜、已购一般、意向未买、流失）→ 签收后回访 → 复购节点。
- 老客激活：按 3 个月/6 个月未复购分层 1v1 激活，配合会员权益和扩品类。
- 未转化用户：设置跟进期，到期换钩子召回；不连续骚扰（开课前反复电话语音提醒是高风险做法）。
- 社群日常：固定时段推送、值班福利官、只发正向内容、售后问题转私聊；老带新双方得券。
- 私域回流公域：社群福利引导回直播间；或在小程序内完成闭环。
- 群发纪律：克制群发和私戳，钩子本身要有价值；只会卖货的私域会伤害大多数客户的信任。

## 5. 知识付费/高客单私域转化链

公域直播（信任 + 筛选）→ 引流品/留资 → 企微/班主任 → 公开课或私域直播（第一轮促单在开播 20–30 分钟）→ 1v1 咨询 → 正价/高客单 → 训练营内二次转化。黄金 48 小时内安排第一次深度触达。详见 `model-knowledge-leads.md` 第 7 节。

## 6. 指标参考

| 指标 | 参考 | 条件 |
|---|---|---|
| 预约进场率 | 视频号 60%–70% 为高水平；其他平台 30%–40% | 河林 |
| 包裹卡扫码/通过率 | 约 5%–20%（配合电话/外呼可更高） | 品牌电商 |
| 私域贡献整场成交 | 约三到四成 | 河林，视频号专场 |
| 私域在 GMV 中的占比 | 起盘期高、放量期降低、成熟期回升 | 品牌/原产地商家 |
| 直播间下单后加好友率 | 约 70% | 知识付费，约 2021 |
| 社群活跃周期 | 约 3–5 天 | 约 2022 起 |

数字仅作量级参考，按账号历史数据校准。

## 7. 红线

- 只用平台允许的导流组件和路径；规则收紧时间线见各平台文件。
- 不使用藏联系方式、多号分散导流、刮刮卡乱码、拉人返现、买号改标签、粉丝群踢人等灰色手法。
- 不以转发朋友圈作为领奖条件。
- 用户数据经同意后存储，提醒社群注意隐私安全；不做高频骚扰。
