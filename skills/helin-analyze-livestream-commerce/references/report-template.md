# 【直播间/场次】直播拆解报告

## 全文摘要

用2至3句话说明：

- 品类或行业；
- 直播时长，注明实际或估算；
- 可识别产品数量；
- 判定的主推品及其主要依据；
- 如为节选或截断稿，立即说明分析范围。

### 2.2 排品策略归纳

**一句话策略模型：** 福利开场 → …… → 主推返场

1. 为什么这样命名；
2. 各阶段如何衔接；
3. 哪些是文稿事实，哪些是策略推断；
4. 这种安排可能服务于什么目标，但不要声称目标已经实现。

## 模块五：综合点评

### 最值得学习的亮点

只写1至3个，每个按以下结构：

1. **具体动作/话术/策略**：发生了什么。
2. **为什么有效或值得借鉴**：解释机制。
3. **文稿依据**：时间点、位置或短证据。
4. **可复制边界**：什么情况下适用，什么情况下不应照搬。

### 明显可优化之处

有证据才写。每项按“问题表现 → 文稿依据 → 可能影响 → 具体改法”展开。没有明显问题时直接写：

“基于现有文稿，未发现证据充分且值得单独提出的明显问题。”

### 结论

用一段高密度结论概括这场直播最核心的打法、最值得迁移的能力，以及分析受限于哪些缺失信息。
